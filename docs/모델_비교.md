# sLLM 베이스 모델 비교 (2026-09-17 기준)

파인튜닝 베이스 모델을 고르면서 조사한 내용. 설계서·교육자료에서 "왜 이 모델을 골랐는가"를 설명할 때 이 문서를 근거로 쓴다.

## 선정 기준

1. **상업적 이용이 가능한 라이선스** — "상용 수준"을 전제로 하므로, 연구·비상업 전용 라이선스는 제외
2. **한국어 품질** — 산업안전 도메인 한국어 문서/알림 생성이 목적
3. **엣지 배포 가능한 크기** — 1~3B급(CPU 추론 목표) + GPU 서버용 더 큰 모델도 같은 계열이면 유리(운영 단순화)

## 비교표

| 모델 | 라이선스 | 상업 이용 | 한국어 품질 | 크기 옵션 | 비고 |
|---|---|---|---|---|---|
| **Qwen3** (Alibaba) | Apache 2.0 | ✅ 제약 없음 | 다국어 최상위권 | 0.6B/1.7B/4B/8B/14B/32B + MoE(30B-A3B 등) | **채택.** 크기 선택지가 넓어 엣지(0.6~4B)부터 GPU서버용 대형까지 한 계열로 커버 가능 |
| Gemma 3/4 (Google) | Gemma 라이선스(상업 허용, 일부 금지행위 조항 — 순수 Apache 2.0은 아님) | ✅ 조건부 | 양호 | 1B/4B/12B/27B | Gemma 3 4B가 RAM 4.2GB로 메모리 효율 최고 — GPU 없는 엣지에 특히 유리. 차선책으로 고려 |
| DeepSeek V4 | MIT | ✅ 제약 없음 | 중국어·영어 중심, 한국어 검증 덜 됨 | 다양 | 라이선스는 제일 깨끗하지만 한국어는 우리 용도엔 불확실해서 보류 |
| Llama 4 (Meta) | Meta 커뮤니티 라이선스 | ⚠️ 조건부 | 양호 | 다양 | MAU 7억 초과 기업 사용 금지, EU 멀티모달 제외 조항 — 그립 규모엔 문제 없지만 Apache 2.0만큼 깨끗하진 않아 우선순위 낮춤 |
| EXAONE 4.0 (LG) | EXAONE 라이선스 1.2 — **NC(비상업)** | ❌ 상업 불가 | **한국어 최상**(한국 기업의 한국어 특화 모델) | 1.2B~32B | 한국어 품질 평가는 가장 좋지만 기본 라이선스가 연구·교육 목적으로 제한됨. FriendliAI 같은 유료 파트너 경유해야 상업 이용 가능 — **이번엔 제외** |
| **Upstage Solar** (Solar Mini/Pro/Open/Open2) | Solar 라이선스(Apache 2.0 기반, "Solar" 이름 포함 + "Built with Solar" 표기 의무) | ✅ 조건부(표기 의무) | 한국어 우수(한국 기업) | 최소 10.7B(Solar Mini)부터 시작, 대부분 22B~250B급 | **엣지 목표(1~3B)에 맞는 소형 공개 모델이 없음** — 가장 작은 공개 가중치도 10.7B로 엣지엔 부적합. GPU 서버에서 "선생 모델"(고품질 합성 데이터 생성용)로는 후보가 될 수 있음(22B급 Solar Pro는 4bit 양자화 시 20GB GPU 한 장에 들어갈 가능성) |

## 결론 — Qwen3 채택

- **베이스 모델**: `Qwen/Qwen3-4B-Instruct-2507` (엣지 목표 크기와 GPU 서버 검증 편의를 절충)
- 기존에 Qwen2.5-3B-Instruct로 파인튜닝 배관(학습→MLflow 기록→평가)을 검증했었고, 같은 라이선스 계열의 최신 세대로 교체 — 코드 변경은 모델 이름 한 줄, 순수 개선
- EXAONE·Upstage는 한국어 품질만 보면 매력적이지만 각각 라이선스(비상업)·크기(엣지에 안 맞음) 이유로 이번 선택에서 제외. 다만 Upstage Solar Pro는 "GPU 서버에서 합성 데이터 생성용 선생 모델"이라는 별도 용도로는 향후 고려 대상으로 남겨둠([[data-extraction-pipeline]]과 별개로, 학습 데이터 품질 개선 옵션)
