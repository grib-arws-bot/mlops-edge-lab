1. 주제 · 의견
키워드로 균형 잡힌 주제를 만들거나 직접 입력하세요. "학생 의견 생성"은 전부 AI 에뮬레이션입니다(실제 학생 데이터 아님).
2. 토론팀 배정
팀 수를 정하면 의견을 벡터로 바꿔 최대한 균등하게 묶습니다(임베딩+k-means, LLM은 팀 이름만 붙입니다). "재배치"로 다시 묶어볼 수 있습니다.
3. 토론 진행
각 팀은 받은 근거자료를 참고해 토론했다고 가정합니다. 아래 버튼을 누르면 같은 에뮬레이션 학생들이 토론 후 의견을 다시 냅니다.
4. 토론 결과
왼쪽(토론 전) → 오른쪽(토론 후) 팀 흐름입니다 — 굵기가 인원 수, 초록 띠는 유지, 주황 띠는 다른 팀으로 이동을 나타냅니다.
