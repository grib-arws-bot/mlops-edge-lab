데이터 드리프트 감지
Evidently는 운영 중인 모델·데이터의 품질을 통계적으로 점검해주는 오픈소스 라이브러리입니다. 아래 용어로 검색 품질이 바뀌었는지를 봅니다.
  • reference(기준) — "정상일 때" 값의 분포. 여기서는 실제 코퍼스 문서에서 LLM이 초안한 질문 116건으로 측정한 top-1 검색 유사도 점수 모음입니다.
  • current(현재) — 지금 실서비스 쿼리(MSDS 검색·산업안전 통합관제·Agent SOP 검색)에서 최근 쌓인 같은 종류의 점수 모음입니다.
  • PSI(Population Stability Index) — reference와 current 두 분포가 서로 얼마나 달라졌는지 하나의 숫자로 나타내는 지표. 원래 신용평가 모델의 입력 변수 변화를 감시하던 금융권 표준 지표를 가져와 씁니다 — 값이 클수록 두 분포가 겹치지 않고 멀어졌다는 뜻입니다.
  • Data Drift(데이터 드리프트) — 들어오는 데이터 자체의 분포가 바뀌는 것(예: 질문 유형이 달라져 검색 점수대가 낮아짐). 여기서 PSI로 감지하는 게 바로 이것입니다.
  • Concept Drift(컨셉 드리프트) — 데이터 분포는 그대로인데 입력-출력 관계 자체가 바뀌는 것(예: 같은 질문이어도 예전엔 맞던 답이 지금은 틀림). 이 카드는 검색 점수 분포만 보므로 Data Drift 전용이고, Concept Drift는 아직 이 프로젝트에서 별도로 측정하지 않습니다.
판정(<2 안정 / 2~8 중간 / >8 드리프트)은 코드 규칙이 정하고, 되돌리기(Rollback)는 사람이 아래 버튼을 눌러야만 실행됩니다. 이 임계치는 업계 관례값(보통 0.1/0.25)이 아니라, "진짜 드리프트가 없는 정상 상황"을 직접 반복 실측해서 이 지표(RAG 검색 점수)에 맞게 새로 잡은 값입니다 — 자세한 이유는 코드 주석(rag/drift_check.py) 참고. 각 확인 시점의 리포트는 Evidently 셀프호스팅 UI 워크스페이스에도 이력으로 쌓입니다(의사결정_로그 126번, 서버 관리자 포트포워딩 승인 대기 중이라 아직 외부 접속은 불가).
