화장품 제조 AX — AI Agent PoC

강원정보문화산업진흥원 제안서 Layer 4(AI 에이전트) 검증용 — concept 검증 목적. Layer 1~3(장비·데이터·AI 예측모델)은 전부 mock 시나리오이며 실제 설비·학습된 모델과 연동돼 있지 않습니다. Layer 4의 판단·답변만 실제 sLLM 호출입니다.

시나리오 데모 — 발효 공정 DO 이상 감지 → 조치
왼쪽부터 장비(Layer 1) → 시계열 데이터(Layer 2) → AI 분석 4종(Layer 3) → AI Agent(Layer 4, sLLM)로 데이터가 흐릅니다. 데이터는 정상 범위 안에서 무작위로 흔들리며 계속 생성됩니다. "악화 시작"을 누르면 그 순간부터 DO가 계속 나빠지는 방향으로, "정상으로 회복"을 누르면 다시 정상 범위로 돌아오는 방향으로 데이터가 만들어집니다. SOP 기준을 벗어나면 Agent가 자동으로 SOP를 근거로 판단해 권고하고, 운영자가 승인하면 그 결과가 Layer 1 장비 상태에 반영됩니다.
